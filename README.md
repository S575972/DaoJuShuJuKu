本研究所用数据均来源于本项目团队依托齐鲁理工学院实验平台采集并开源的 SDU-QIT 立铣刀加速寿命试验数据集
。该数据集是国内首个聚焦于变工况条件下的机床立铣刀加速寿命试验公开数据集，在山东省重大科技创新工程项目支持下，于 VDF-850 立式加工中心上采集
包含 2 种工况下 6 把立铣刀的全寿命周期三轴振动信号（KS903 传感器，10 kHz 采样），
并标注了主 / 副后刀面磨损宽度 VB 与磨损面积 S_VB 共 5 类标签，覆盖刀具从初期磨损到急剧磨损的完整演化阶段，
可为刀具磨损状态识别与剩余寿命预测算法提供了可靠的数据支撑
